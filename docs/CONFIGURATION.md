# Configuration Reference

This document separates the configuration files used by the installed product, the Runtime Supervisor, the Bridge, and external runtimes.

## Product and runtime selection

Path:

```text
%LOCALAPPDATA%\TiaAgent\config.json
```

Model:

```json
{
  "defaultRuntime": "opencode",
  "updateChannel": "stable",
  "runtimes": {
    "opencode": {
      "enabled": true,
      "executable": "opencode",
      "mode": "server",
      "serverUrl": "http://127.0.0.1:43120",
      "environment": {}
    }
  }
}
```

Supported fields:

| Field | Meaning |
|---|---|
| `defaultRuntime` | Default runtime ID. |
| `updateChannel` | `stable`, `rc`, `beta`, or `alpha`. |
| `runtimes.<id>.enabled` | Enables or disables one registered runtime. |
| `runtimes.<id>.executable` | Executable name or explicit path. |
| `runtimes.<id>.mode` | `cli` or `server`, subject to adapter support. |
| `runtimes.<id>.serverUrl` | Server endpoint for server mode. |
| `runtimes.<id>.environment` | Extra child-process environment values supported by the configuration model. |

The current `tia-agent config set` command can modify `enabled`, `executable`, `mode`, and `serverUrl`. It does not provide a setter for individual `environment` entries.

Use:

```powershell
tia-agent config list
tia-agent config get defaultRuntime
tia-agent config set defaultRuntime claude
tia-agent config path
tia-agent config reset
```

## Runtime Supervisor ports

Default path:

```text
%LOCALAPPDATA%\TiaAgent\config\settings.json
```

A different file can be supplied with:

```powershell
tia-agent start --config C:\path\to\settings.json
```

Implemented settings:

```json
{
  "schemaVersion": 1,
  "preferredPorts": {
    "bridge": 43119,
    "opencode": 43120
  },
  "portRange": {
    "start": 43100,
    "end": 43200
  }
}
```

The supervisor currently reads only `preferredPorts.bridge`, `preferredPorts.opencode`, `portRange.start`, and `portRange.end`. If a preferred port is unavailable, it selects another port from the configured range.

The maintained template is `config/settings.example.json`.

## Bridge configuration

Path generated by the Runtime Supervisor:

```text
%LOCALAPPDATA%\TiaAgent\bridge.json
```

Fields:

```json
{
  "port": 43119,
  "openCodeBaseUrl": "http://127.0.0.1:43120",
  "taskTimeoutSeconds": 300,
  "maxConcurrentTasks": 5,
  "maxRequestBodyBytes": 1048576
}
```

The supervisor rewrites this file with the ports allocated for the current run. `config/bridge.example.json` documents the same schema.

## OpenCode template

`config/opencode.example.json` contains the repository template for:

- the local server port;
- the `tia-mcp` stdio command;
- the available agent profiles;
- a model-provider example.

The model provider and model name are examples, not product requirements. Users must configure a provider supported by their installed OpenCode version.

## Environment variables

### User-facing runtime override

| Variable | Used by | Meaning |
|---|---|---|
| `TIA_AGENT_RUNTIME` | Runtime Supervisor and Bridge selection | Overrides `defaultRuntime` for the current process environment. |

Example:

```powershell
$env:TIA_AGENT_RUNTIME = "claude"
tia-agent start
```

### TIA Portal build and discovery

| Variable/property | Used by | Meaning |
|---|---|---|
| `TiaPublicApiDir` | MSBuild and CLI TIA discovery | Explicit V21 Public API directory. |
| `TiaAddInApiDir` | MSBuild | Explicit V21 Add-In assembly directory; defaults to `TiaPublicApiDir`. |
| `TIA_AGENT_VERSION` | `build.ps1` | Optional build-version input when `-Version` is not supplied. |

`TiaPublicApiDir` is also checked by `tia-agent` when discovering the TIA Portal V21 installation.

### Internal variables

`TIA_AGENT_INSTANCE_ID` is assigned by the Runtime Supervisor to child processes. It is internal runtime metadata and is not a user configuration interface.

## Credentials and generated state

| Path | Purpose |
|---|---|
| `%LOCALAPPDATA%\TiaAgent\bridge.token` | Bridge bearer token created or reused by the Bridge. |
| `%LOCALAPPDATA%\TiaAgent\runtime\runtime.json` | Current service-discovery manifest. |
| `%LOCALAPPDATA%\TiaAgent\runtime\secrets\` | Transient supervisor-generated runtime secrets. |

Do not commit, print, or publish generated token files.

## Precedence summary

Runtime selection follows:

1. task-request override;
2. `TIA_AGENT_RUNTIME`;
3. `defaultRuntime` in `config.json`;
4. `opencode`.

Port selection follows:

1. an explicit `--config` settings file;
2. `%LOCALAPPDATA%\TiaAgent\config\settings.json`;
3. compiled defaults;
4. another available port within the configured range when the preferred port is occupied.

See [RUNTIME.md](RUNTIME.md) for runtime behavior and [CLI.md](CLI.md) for command syntax.
